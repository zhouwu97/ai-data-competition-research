# 字段可用时点检查表

先写预测/决策时点、观察对象和观察周期。同一字段用于当前描述与未来预测时，允许使用范围可能不同。

| 字段 | 含义 / 单位 | 事件时间 | 实际取得时间 | 当时是否可用 | 拟合统计量用什么数据 | 决定与证据 |
| --- | --- | --- | --- | --- | --- | --- |
| 教学日历星期 | 已知日期的星期 | 目标预测日 | 预测前可知 | 是 | 不需要从未来销量拟合 | 题一日历特征可用 |
| 教学未来销量 | 未来目标答案 / 件 | 目标预测日结束后 | 未来才知道 | 否 | 不能进入特征 | 只能用作后来评估答案 |
| 历史订单补录 | 过去订单 / 件 | 01-01 | 01-03 | 01-02预测不可用 | 按真实取得时点筛选 | 不能只看订单日期 |
| 待填实际字段 | | | | | | |

检查数据来源、补录、修订和计算过程。字段名含“历史”不保证没有未来信息；人工推断可用时点时应保留待确认状态。
