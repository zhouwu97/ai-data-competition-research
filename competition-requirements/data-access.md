# 怎样正规取得赛题数据

数据拿到手并能解释字段，才开始正式选题试做。这里提供操作顺序，不代替报名。

## 长风杯：先开通课程和平台权限

依据[2025东北赛区通知](https://www.lncu.edu.cn/cxcyxy/28215.html)“竞赛内容与方式”第一部分：赛题数据已集成在蓝鲸数据挖掘实验平台、魔笛Python实验平台；队长先报名，再用课程邀请码取得学习权限，课程中可以直接访问工具。

1. 从**本届正式通知**确认报名地址、队伍资格和队长；完成自己的报名。
2. 队长按通知取得课程邀请码，在[长风云实训课程](http://training.cfnet.org.cn/course)注册并加入对应实训。2025通知通过赛事群提供邀请码；不要把旧群号当作2026流程。
3. 在指定蓝鲸或魔笛课程加载赛题数据。先查看表名、字段、日期范围、样本行和平台提供的数据说明。
4. 问清楚是否可以导出，或者必须在平台内计算。如果只能平台内使用，保存允许导出的汇总结果、代码、运行记录即可。
5. 记录数据取得日期、适用题号、权限说明和版本。数据本身留在允许的地方，不随资料仓库公开。

本轮没有登录这些平台，也没有取得正式数据。若本届入口或权限不通，把卡住的步骤、提示和队伍报名状态交给校内负责人确认；同时用[教学数据](../examples/README.md)练方法，正式选题结论留待字段审查。

## 海豚杯：按赛道取得正文与数据

[2026辽宁工程技术大学通知](https://cxxy.lntu.edu.cn/info/1134/5435.htm)给出[海豚杯官网](https://competition.wd.dilabs.cn/2026DICompetition)及操作指南附件。先确认赛道和参赛状态，再在正常平台入口获取题目、模板、数据及作品要求。校赛页的操作指南附件有验证码，本轮只确认附件存在。

不要从往届GitHub项目倒推2026字段，也不要把一个学校的邮箱与校内截止用于其他学校。官网、赛区和本校通知冲突时，向适用赛事负责人取得明确答复，记录采用哪份要求。

## 数据字典只需先填这些

| 字段或问题 | 要记什么 | 例子 |
| --- | --- | --- |
| 一行代表什么 | 统计单位与主键 | 一条运单；订单+商品，而非一张订单 |
| 时间 | 事件时间、统计周期、预测时可用时点 | 运单创建日；业务量按月结算 |
| 数量与单位 | 件、箱、重量、金额，含不含退货 | 箱数不能直接与件数求和 |
| 关联键 | 客户/商品/城市ID；关联关系 | 客户汇总表是否每个ID只有一行 |
| 缺失与异常 | 0和空值含义、取消单、重复行 | 0销量可能是缺货，并非0需求 |
| 使用范围 | 能否导出、共享、用外部数据或工具 | 允许团队计算，不允许公开原始运单 |

先对照这些问题看20行样本和汇总统计，关键口径不清就先问，避免给模型喂错目标。

## 企业客户数据怎样配合AI使用

使用权限与数据分析能力是两回事。检查数据提供方和比赛是否允许发给第三方AI；权限未明确时，可用**虚构样例、不含原始数据的报错、允许分享的字段说明与汇总结果**讨论，原始客户或运单留在授权环境。

删姓名不一定消除识别风险，客户ID、精确地址或稀有交易也可能识别人。若允许导出，再按数据方约定处理标识、访问范围和保存期限。这些确认通常一份数据说明或负责人的明确答复就能记录，不需要另建复杂审批系统。
