## 四题要读清的地方

2025题三明确要求应用K均值；题四具体任务写的是“聚类算法（如K-means）”。题四可以比较其他聚类路线，选法要服务客户特征与差异化策略。

题三背景给出每日约270公里、下单后两日送达。把它用于实验时，先说明是单程运输、往返作业还是直线距离代理，再设半径；不能只把两个数字相乘就认定服务承诺已实现。题一同时要求区域需求分析与总仓未来两周趋势，正式预测粒度按数据和评分附件落实。

## AI、开源与数据：把问题问具体

辽宁工业大学2025校赛禁止利用网络资源或AI拼凑、买卖、仿造作品，并禁止抄袭、伪造或篡改数据。它没有逐项说明所有AI辅助场景的许可边界，也不是本届全国统一政策。

向适用赛事负责人确认三件事即可：**AI能辅助哪些环节、需要怎样披露；外部代码与数据能否使用；正式数据能否导出或交给第三方工具。** 保留原始来源、开源许可证和自己的改动，报告里的成绩对应实际实验。合成数据标为教学或模拟结果。
