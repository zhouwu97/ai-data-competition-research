# 比赛路线与复盘分析专项

核查日期：2026-10-08。目标是把他人的参赛经历转化成可执行的实验与交付决策。

本轮选择 **6 个案例**：2 份连续实验复盘、2 份高排名方案、2 份国内杯赛作品审读。材料完整程度不同，因此分别说明作者记录、代码观察和本仓库分析。所有成绩与名次均来自作者公开材料，未独立核验；本轮没有训练模型或提交比赛。

## 读复盘的判断标准

一个有用的复盘应回答：起点是什么；为什么做这个改动；和谁在什么切分上比较；结果有什么波动；哪些结论撤回了；下次怎样改变流程。只给最终架构与成绩的项目，不能据此还原完整参赛时间线。

国内杯赛的公开检索目前仍以此前两份作品为主要直接材料。本轮没有找到足以核验的新完整参赛复盘，不把 Kaggle 方法说成国内获奖秘诀。下一轮优先补官方评分表、允许使用的数据和实际复现实验。
