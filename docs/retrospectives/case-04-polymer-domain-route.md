# 案例 04：领域信息怎样进入模型，以及工程成本在哪里

对象：jday96314/NeurIPS-polymer-prediction，作者称 2025 聚合物预测第 1 名。依据：[仓库路线](https://github.com/jday96314/NeurIPS-polymer-prediction/blob/a7a2bc90e6f5e6f1f3e00ab556e4f7ff555aae53/README.md)、[最终训练入口](https://github.com/jday96314/NeurIPS-polymer-prediction/blob/a7a2bc90e6f5e6f1f3e00ab556e4f7ff555aae53/train_winning_ensemble.sh)。未独立核验排名或复现结果。

## 已读路线与证据

仓库结合表格、BERT、Uni-Mol 和模拟相关方法，保留赛末工作区 old_experiments。最终脚本依次下载比赛与多份额外数据、准备标签、生成模型所需数据，再训练各分支。README 建议 Python 3.11 与至少 24 GB 显存。

入口脚本会安装并升级依赖，注释还说明部分包版本存在冲突；数据下载依赖外部服务。它是最终重建路线，不能仅凭目录判断哪个分支贡献最大、具体训练总时长或完整实验先后。

## 本仓库分析

高排名方案不一定主要来自调参，也可能依赖对领域信息的组织。但仅凭最终脚本不能做因果归因。要判断外部数据、预训练或模拟的增益，需要在同一验证设计上做删减比较。

“保留旧实验”和“最终入口简洁”可以同时做到：最终训练列出所需步骤，归档保留未采用分支及原因。工程可复现性还需锁定环境和输入，不能把一个 shell 文件的存在称为已验证的一键复现。

## 我们采用的删减路线

1. 列出各数据源、可获得时点、许可证、赛规用途及目标字段，标出比赛之外的信息。
2. 只用比赛提供的字段建立基线；再逐项增加允许使用的外部信息或领域特征。
3. 固定切分，对各分支做加入 / 移除比较，同时记录下载、预处理、训练与推理成本。
4. 只有稳定收益足以覆盖成本时才保留复杂分支；环境修正与性能改动分别记账。
