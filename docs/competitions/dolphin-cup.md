# 海豚杯：2026 资料核查

## 身份与入口

这里指大学生“海豚杯”数智应用创新大赛。高校通知链接到 [2026 官网](https://competition.wd.dilabs.cn/2026DICompetition)，并提供 [辽宁省平台](http://cxcy.upln.cn/)。官网正文此次读取失败，2026 信息主要依据高校公开通知。

辽宁相关赛事有数智分析、数智应用创新、数字化人才智能仿真三类赛道。通知要求前两类同时在省平台与海豚平台报名；第三类仅省平台。第三赛道属于辽宁赛安排，不据此断言海豚杯全国赛也有相同第三赛道。
