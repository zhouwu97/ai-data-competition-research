# 资料和实验分别验证了什么

这是教学与竞赛研究仓库。输入、结果与来源用下面五种说明，其他页面只在假设影响局部判断时补充限制。

| 状态 | 代表什么 | 这里的例子 |
| --- | --- | --- |
| 官方已确认 | 已读适用范围明确的原始通知 | [赛事要求](../../competition-requirements/README.md)中的往届任务和地方通知 |
| 作者自述 | 上游作者报告的方法或成绩 | [六个复盘案例](../retrospectives/README.md)，没有独立确认的名次保留这个标记 |
| 本仓库已执行 | 指定输入、代码、命令确实生成了所列结果 | [教学练习](../../examples/results/report.md)使用合成数据；[吉林配送研究](../../research/lade-jilin/README.md)使用公开真实记录，保留数据版本及预测明细 |
| 理论或条件推断 | 由公式或明确假设推得的判断 | 最优最大覆盖的单调性、代理距离和模拟搬货成本；不是实测收益 |
| 待核实 | 尚未取得足够依据 | 当届完整评分、正式数据、参赛效果与获奖可能性 |

文件SHA256检查“运行后文件是否变了”。[教学独立计算检查](../../scripts/check_calculations.py)从原始输入和逐条输出重新计算指定指标；[真实研究检查](../../scripts/check_public_research.py)从已保存逐条预测重算窗口、总体、长尾、诊断及报告指标，范围见[说明](../../tests/README.md)。前者不能证明公式正确，独立重算也不能证明模型适合真实企业或满足全部评分。

正式数据和账号权限从[数据获取说明](../../competition-requirements/data-access.md)开始。实验不把合成数据标成真实；地方校赛标准也不当作全国标准。


## 2026-10-23题一智能分仓深度学习实验

输入来自作者公开的[往届长风杯固定目录](https://github.com/hzy-sunstone/ai-journey-notebooks/tree/09d9ec99415ddde7c817e9fb83b4706bb572b17f/%E9%95%BF%E9%A3%8E%E6%9D%AF%E9%A1%B9%E7%9B%AE)，本机原库SHA256为`58037e65d54b781f610e6c6ea73325ab42948084475d4c70aabc6381bcb2861e`。作者文件不代替当届平台数据。只读实查232,621行、1,000商品、453日期；只有99商品全期有记录，缺商品日不当零需求。Cost有商品与仓口径，行为表却没有区域或仓字段，不能补出历史分仓销量。原始SQLite不提交，用户需自行取得同版本原库。

[审计脚本](../../research/smart-demand/audit.py)检查全部字段，独立SQL核对商品和日期汇总；[审计报告](../../research/smart-demand/results/data_audit.md)保留字段口径与异常。目标是`qty_alipay`已记录成交，不能称潜在需求。全国每日总量直接预测；共享商品模型只在有真值格子评价并报告覆盖，不用未来记录名单构造全国预测。

[配置](../../research/smart-demand/config.json)固定六个开发、六个后段14天窗口。开发用一个种子选择三个MLP中的候选与中位数，后段对入选MLP运行三个种子并固定平均。72次拟合已经执行；全国MLP日MAE5,736.10件，中位数5,346.63件；商品MLP为10.0495件/商品日，中位数10.0030件/商品日，分别仅1/6和2/6窗口改善，三个种子总体也都更差。[完整报告](../../research/smart-demand/results/report.md)、[汇总](../../research/smart-demand/results/summary.json)与[独立重算入口](../../research/smart-demand/verify.py)保留结果。逐条预测留在原本机输出目录，复现命令会重建；大明细与训练输出不提交。

全量审计已经查看日期、覆盖和极值，因此后段是设置冻结后的历史时间评价，不是前瞻盲测。该结果只说明本轮三个固定设置未胜出；均值锚点、容量轮数及行为表示仍有待验证的对照，不是已证实改进。
