# 为什么摘要一致还不够？

一次隔离副本实验把题一 MAE 公式除以10，再重建全部结果。一个日历模型窗口从逐日预测重算为3.984467，程序却报告0.398447；旧的研究检查及5项元数据测试仍通过。原仓库未被修改。

原因很简单：程序算错，JSON和报告一起使用错误值，文件摘要仍能完全对应。SHA256像文件指纹，能发现版本不同，不判断公式对错。

## 现在怎样检查

[check_calculations.py](../../scripts/check_calculations.py)不调用建模代码或 sklearn 指标，而从原始输入与逐条结果用独立公式重算。覆盖 MAE/RMSE、每日 EIQ与ABC边界、最近中心与覆盖、客户特征及轮廓系数/ARI；压力情景也保存逐条预测、策略行动与分组，用同一检查入口重算。详细范围见[测试说明](../../tests/README.md)。

```bash
python examples/run_all.py
python scripts/validate_research.py
python -m unittest discover -s tests -v
```

完整运行最后执行独立检查，失败就停止，不生成新的成功汇总。研究检查先核对版本和报告，再调用独立重算。[测试](../../tests/test_calculations.py)使用手算小数据，也故意篡改结果并同步摘要，要求错误仍被发现。它还检查固定中心时扩大半径不会减少覆盖；不要求重新拟合 K-means 增加K后覆盖必然提高。

本轮实际跑完9个步骤、18项计算测试和原有5项元数据测试。另在临时副本直接把题一源码MAE除以10，重跑完整流程：独立检查发现一个近期均值窗口报告1.707143、重算17.0714286，流程返回1，原成功摘要没有被覆写。这比只改结果文件多验证了生成链路；临时错误不进入仓库。

这解决的是这些已保存数字的正确性。是否用了恰当目标、数据有没有代表性、策略能否帮助真实业务，要继续做[决策对照](decision-cases.md)。测试通过不是模型有效性的替代品。
