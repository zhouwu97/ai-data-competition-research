# 四周入门与备赛路线

面向会一些编程、数据分析流程尚不熟悉的个人或社团。每周成果是建议，可以按实际时间缩减。

| 周 | 做什么 | 完成标志 | 推荐资料 |
| --- | --- | --- | --- |
| 1 | Python / pandas 读取、筛选、分组、合并、缺失处理和画图 | 一份数据字典与质量报告，能解释三个发现 | 动手学数据分析、Joyful Pandas |
| 2 | 在 Kaggle 入门题做本地验证、baseline、提交 | 可重跑代码、一次有效提交、实验日志 | Titanic、House Prices、competition-baseline |
| 3 | 选择一个国内赛事方向，复现一份同类方案 | 填好复现卡；跑不通也有明确环境和数据缺口 | 海豚杯文本项目；长风杯需求预测 / 分群练习 |
| 4 | 完成图表、报告、演示和答辩 | 代码版本固定，报告每个核心结论有数据或实验支撑 | 报告提纲与实验模板 |

## 个人起步

先用 CPU 跑小样本和树模型，实际测耗时与内存，再决定是否购买算力。预训练文本模型、图像模型和大型集成各自的预算不同，不能用模型参数量替代真实资源估算。

## 社团协作

建议四个职责：赛事与数据、验证与模型、图表与解释、报告与演示。人数少可以合并职责；每个人至少理解目标和验证方式。共享 Git 代码与实验记录，大文件放合规数据存储并写下载说明。

## 第一个练习题怎么挑

优先级由四项决定：数据能否合法取得、目标是否清楚、简单方法能否跑通、能否说出结果用途。如果某题只能做漂亮界面、没有数据或评估路径，暂不把它当主项目。

建议先做一个完整题目，再扩展到同类比赛。资料库更新围绕正在解决的问题，每条新链接至少写一句用途与一条限制。
