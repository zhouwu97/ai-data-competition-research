# 数据与验证：怎样知道自己做对了？

模型输出一个数并不困难，困难的是让比较可信。先知道一行数据是谁、每列是什么意思、预测时哪些信息已经存在。

## 1. 为什么要有简单基线？

假设昨天和前几天每天大约卖20件，直接预测明天20件就是一个简单基线。新模型若只比它稍好，却更慢、更难维护，就要解释是否值得。

基线不是故意做差的对手。预测练习同时比较最近7天均值和最近28天同星期均值，然后才比较日历趋势模型。正式数据如果有更适合的现有方法，应当把它纳入对照。

## 2. MAE和RMSE用一个例子说明

真实值为10、20、30，预测为12、18、35，误差绝对值为2、2、5。MAE=(2+2+5)/3=3。表示这三条记录平均差3个单位。

RMSE先平方再平均再开方：平方误差为4、4、25，平均为11，开方约3.3166。它对大的误差更敏感。两者通常越低越好，但比赛到底用什么看评分表。

件数误差、百分比误差、城市覆盖率和轮廓系数不是同一种量。不能跨题直接按指标数值挑赛题。真实值接近0时，百分比类误差还要专门审查定义。

MAE定义依据：[官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.mean_absolute_error.html)。

## 3. 什么是回测？

假装自己站在过去某一天，只用那天以前能获得的信息预测后来的14天。等于用已经发生的历史检验“当时不知道未来”的方法。

教学数据112天，依次用前56、70、84、98天训练，每次预测后14天。四段验证不重叠，但训练集会逐渐增加；它们仍来自同一合成过程，并非四次独立现实试验。

同一轮的所有方法用相同日期和实际值比较。先固定比较方法，再读结果；一直根据同一验证集改动也可能造成选择偏差。

## 4. 哪些东西属于泄漏？

用未来销量、客户流失后才产生的状态、后来才补录的字段，或者先拿全量数据计算会影响预测的统计量，都可能让验证失真。

字段记录日期不等于你真正取得它的日期。例如2025-01-01订单在01-03才补录，01-02的预测当时不知道它。需要[字段可用时点表](../../templates/feature-availability.md)。

预处理若需要学习均值、标准差、填补值或筛选规则，在预测验证中应只在训练部分拟合，再应用到验证。描述某个观察时点全部客户的分群，和评估未来客户，是不同任务；不能机械把一种切分规则用在所有分析里。

## 5. 分群、仓储和选址怎样检查？

分群没有真实等级时，可以检查数据整合、群体画像、规则对照、初始化与时间稳定性。内部几何指标好，不证明营销有效。

仓储可以核对EQ与IQ合计、EN是否数不同SKU、每天是否独立分析、ABC边界是否一致，再检验策略假设。

选址先说明距离、服务阈值与覆盖分母。例如覆盖8/10个城市是80%城市覆盖率，不代表80%需求覆盖率。聚类中心、可建站点、道路时效和现实最优方案是不同层次。

## 6. 怎么避免AI写出没有运行的结论？

看日志的命令、退出状态、输入和源码版本，打开实际结果文件。数字应对应明确字段。教学练习的run_manifest.json保存文件SHA256摘要，claims.json对应四项汇总数字；这些检查发现变化和不一致，但不能证明所有研究结论正确。

读[错误示范](../../examples/results/failure_cases/report.md)：直接抄答案会得到0误差，恰好说明好指标不是充分证据。
