# EIQ和ABC：先把订单算明白

这不是必须使用机器学习的任务。EIQ是在订单、商品和数量三个角度观察出库；ABC是在选定指标上划分重点管理对象。先定义统计口径，比先选模型更重要。

## 1. E、I、Q是什么？

E表示订单，I表示品项，Q表示数量。不同材料可能用订单、出库单、批次或商品大类作为单位，不能只看缩写就直接套计算。我们的教学练习用日期+订单号识别订单，用SKU识别品项，Q单位是件。

下面都是同一天：

| 订单 | 商品 | 数量 |
| --- | --- | --- |
| O01 | A | 6 |
| O01 | B | 1 |
| O02 | A | 2 |
| O02 | C | 1 |
| O03 | B | 3 |
| O03 | B | 1 |
| O03 | C | 1 |

O03的B有两行，可能是拆行记录。先确认它们不是错误重复，再合并为B共4件。

| 指标 | 问什么 | 手算结果 |
| --- | --- | --- |
| EQ | 每张订单一共有多少件？ | O01=7，O02=3，O03=5 |
| EN | 每张订单有多少种不同SKU？ | 三张订单都是2种；O03不是3种 |
| IQ | 每种SKU一共出了多少件？ | A=8，B=5，C=2 |
| IK | 每种SKU出现在多少张不同订单？ | A=2，B=2，C=2 |

核对：EQ合计7+3+5=15，IQ合计8+5+2=15。如果不一致，先查日期、退货、重复或合并口径。

## 2. ABC怎样做？

先决定按什么排序：出库件数、出库订单频次、销售金额或库存价值，含义不同。教学代码按每日IQ排序。

再计算累计占比。本练习用80%、95%作为两个教学阈值，并规定跨过阈值的品项归前一类。A是从起点累计到至少80%的前一批，B接着累计到至少95%，C为其余。零数量单列ZERO。阈值、边界、同值排序都应写清，不是统一赛规。

上述小样本A=8、B=5、C=2：商品A占53.33%，加入商品B累计86.67%，因此A和B这两个SKU被划入ABC的A类；商品C划入B类，没有C类。这不一定是程序错，而是品项太少、跨界规则导致的结果。

注意“SKU名A”和“ABC的A类”是不同概念。

## 3. 分类后怎样提出策略？

高IQ表示件数多，高IK表示很多订单都要取它。若一个商品只被少数订单大量购买，两者会给不同信号。要结合包装、尺寸、订单品项数、批量和作业条件提出策略假设。

可以研究哪些商品优先安排易取放位置，哪些订单适合分区或合并拣选。完成EIQ/ABC不必已有实际仓库布局；要计算路线节省或宣称实测提效，就必须补相应布局、路线、容量和作业证据。
