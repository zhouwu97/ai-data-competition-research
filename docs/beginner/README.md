# 从零开始：先看这一页

你不需要先会K-means，也不需要先读完所有资源。先用一个很小的例子理解，再运行代码，再考虑正式赛题。

## 先理解你在做什么

数据分析是在回答一个具体问题：发生了什么、为什么值得关注、接下来可以怎样做。机器学习是其中一种工具。预测、分群、订单统计和选址，回答的是不同问题，并不是每个题都必须训练预测模型。

本仓库现在有两种材料：往届赛事与他人方案的研究资料，以及我们实际执行的原创教学练习。教学输入全部是合成数据；正式比赛数据、2026长风杯完整规程与评分表仍未取得。

## 最小学习任务

先在纸上给1、2、8、9分两组并计算均值。再运行手算程序，对照每一轮中心位置。接着打开客户分群练习的profiles.csv，指出每群的订单数、业务量、最近交易间隔，暂时不要给它们贴“高价值”标签。

最后选一份报告，找到一个数字对应的CSV或JSON。能追溯到输入与代码，比记住算法名字更重要。

## 现成教程怎么搭配

[精选教程与章节](learning-resources.md)只列少量当前最有用的入口，说明先读哪部分。第一次学习先读本仓库的中文解释，再查官方接口；不需要先把英文文档看完。

[当前已执行结果](../../examples/results/report.md)可以直接阅读。看到结果不等于自己已经完成复现；运行成功、知道输入是什么、能解释限制，才算完成这个练习。

基础看懂后，进入[按问题研究](../research/README.md)。那里研究模型遇到趋势突变、仓储波动、覆盖冲突和客户变化时会发生什么，不必一开始就读所有专题。
