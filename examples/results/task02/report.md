# 题二教学实验记录

合成订单；没有真实仓库布局或实测效率数据。

原始15行，按日期-订单-SKU汇总后14行，总数量41；EQ合计与IQ合计按天核对通过。

EQ是每单件数，EN是每单不同SKU数，IQ是每SKU件数，IK是含该SKU的不同订单数。数量高和订单出现频繁不是一回事。ABC本例按IQ，不是金额或利润。

80%/95%改为70%/90%后，有1个日期-SKU记录改变类别。两组阈值都是教学假设，不能当作统一赛规。

策略假设：高IK品项可优先研究易取放位置；高EN订单可比较分区或批量拣选。需补充尺寸、通道、容量、路线与实际作业数据才能证明提效。
