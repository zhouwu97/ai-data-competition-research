## 学习和选题分别怎样做？

学习时，四类很小的练习都可以运行，认识不同问题。正式选题时，先用同一张[选题表](../templates/topic-selection-matrix.md)检查四题的数据与任务，再给最有希望的两个候选相近试做预算。先排除无法完成的路线，不要求完整做完四个参赛项目。

预测有清楚误差不等于更值得获奖；仓储不训练模型也可能完成有价值分析。要结合当届评分、真实数据、团队能力和剩余时间判断。

## 研究前先写自己的预测

运行前记录：我预计哪个方法或假设更合适？为什么？什么结果会改变判断？运行后再打开结果。你已见过本仓库结果时，这只能叫复现和学习，不能声称对它做了严格盲分析。
