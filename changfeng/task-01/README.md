# 题一：分仓商品需求预测研究档案

依据：[2025公开任务](https://www.lncu.edu.cn/cxcyxy/28215.html)。正式2026规程、真实数据、评分和预测提交粒度尚未取得。

## 要求与未决问题

任务包括全国总仓与区域分仓的需求分布、区域偏好与波动，以及未来两周全国总仓总体商品需求量趋势。正文同时提到商品需求；不能只凭“总体”就认定一条总量曲线足够。

需要确认：预测目标是销量、出库还是其他需求代理？商品、类目与总体要输出哪些粒度？区域、行为、品牌字段实际存在吗？指标、缺失日和新商品怎样处理？

## 数据前提

日期、商品、区域或仓库、目标数量及字段口径；需要足够历史形成多个匹配14天的回测。浏览和加购等行为还要确认取得时点，不能默认都是可用特征。没有库存/缺货信息时，不把销量直接称为未满足的真实需求。

## 最小路线与评价

先汇总与核对区域和商品分布，再建立近期均值、同星期基线；固定历史窗口后比较一个改进。报告逐窗口、不同对象误差与成本，不只汇报总平均。

[教学代码](../../examples/01_demand_forecast.py)只预测合成全国汇总序列，比较近期均值、同星期均值和日历Ridge；还输出区域-SKU统计。Ridge是带系数约束的线性回归，本例用日期趋势和星期特征，不代表正式题最优算法。

## 继续、修复与停止条件

优先修日期、目标口径和字段可用时点。无法在预算内建立可信时间关系或匹配验证时，停止当前预测路线；一次改进不涨分不能直接换题。

若只有一个可用窗口，保留较弱证据状态，不为了制造多个窗口切得过短。历史跨度按任务与周期判断，不硬性要求某个固定月数。

## 扩展与交付

基线暴露具体问题后，再研究商品层级、促销、缺货或更复杂模型。每项扩展说明需要新增什么字段、如何比较、增加多少成本。

交付应有数据字典、区域分析、预测文件、历史验证、图表、报告、命令与限制，并对应当届格式。

## 已运行教学结果与差距

[实际报告](../../examples/results/task01/report.md)有四个14天回测，代码和输入已留摘要。合成数据刻意含周规律与线性趋势，因此日历模型占优势不能推广到真实数据。

缺少品牌、用户行为、库存和真正区域消费偏好证据；没有实际未来提交、当届评分反馈或业务收益验证。这是一条学习闭环，不是完整参赛作品。
