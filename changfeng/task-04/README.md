# 题四：快递企业客户群识别研究档案

任务依据：[2025公开说明](https://www.lncu.edu.cn/cxcyxy/28215.html)。届次与数据状态见[要求清单](../../competition-requirements/README.md)。

## 要求与未决问题

整合历史运单与业务量，分群，解释高价值、潜力、常规等群体特征，并提出差异化服务与营销。要确认价值定义、观察周期、统计对象和是否有后续结果。

业务量可作为规模代理，但没有利润/成本字段时不能叫利润等级。方法只反映规模不一定失败；关键是是否满足任务并形成有依据的服务差异。

## 数据前提

稳定客户ID、历史行为、业务量、日期与口径。每位客户多张运单先聚合成一行，再检查业务表合并关系。ID只用于连接，不把编号大小作为行为特征。

特征按业务含义选择，说明观察时点和补录数据；选择标准化、对数变换等处理需要理由，不能为了让图分开随意改动。

## 最小路线与评价

先建立按业务规则的简单分组，再用聚类方法比较画像、群体规模、所选空间内的轮廓系数和稳定性。2025任务写的是聚类算法“如K-means”，并非题三那种明确指定K均值的措辞。本教学仍用K-means便于对照；正式方法选择依据任务和数据。对未来使用另看不同时间或新客户。

[代码](../../examples/04_customer_segments.py)聚合合成运单并一对一合并业务量，用订单数、业务量与最近交易间隔分群。比较业务量三档与k=2至5；k=3是固定讲解例子，不是自动决定真实客户等级。

## 继续、修复与停止条件

主键、行为或统计口径不可恢复时停止当前路线。先修不稳定画像与合并错误；一次轮廓系数低不等于换题。

如果结果主要是规模分档，但能解释服务差异，应保留并诚实描述。无法满足规定分群、画像与策略任务，且预算内无法补齐时，才考虑改选。

## 扩展与交付

有成本、利润、投诉、时效或后续行为时，研究价值代理、服务差异与时间稳定性。没有干预与结果数据，营销建议属于假设，不能声称已降低流失。

交付包括客户特征、合并审查、分组、原始单位画像、规则对照、稳定性、策略依据、报告与运行说明。

## 已运行教学结果与差距

[实际报告](../../examples/results/task04/report.md)显示分群与业务量规则较相似，并检查5个额外初始化。尚未验证抽样或未来稳定性，也没有利润、流失或营销效果证据。教学生成机制不提供所谓真实等级答案。

增强路线先处理[弱结构、时间变化与业务口径](../../examples/results/stress/report.md)。如果群体只是连续规模的分档，可以保留简单规则作为服务工具；只有获得额外稳定信息时，才把聚类写成新增发现。
