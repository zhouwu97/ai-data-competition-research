# 题二：仓储运营优化研究档案

依据：[2025公开任务](https://www.lncu.edu.cn/cxcyxy/28215.html)。正式2026规程、真实数据和评分尚未取得。

## 要求与未决问题

按天进行EIQ分析、结合ABC提出差异化拣选策略，并识别高频出库重点品项。应把每日分析、分类口径和策略依据逐项对应，不能只有全期排序图。

需确认订单、SKU、数量、出库日期、退货和取消口径；ABC是按数量、频次还是金额？每日边界、同值排序及阈值是否由赛方指定？

## 数据前提

日期、订单ID、商品ID和数量足以建立基本统计；每行是不是订单-SKU明细需要先查。拆行与错误重复区别清楚，不能直接按行数数订单或品项。

额外路线/效率分析需要货位、布局、作业路径、体积、设备、人员与容量等相应证据。缺少这些不会自动阻止完成规定EIQ/ABC。

## 最小路线与评价

先按日期-订单-SKU规范记录，再算EQ、EN、IQ、IK，核对每日期EQ与IQ合计。按明确指标做ABC，保留跨阈值规则并比较合理阈值变化。

[白话解释](../../docs/beginner/eiq-abc-explained.md)可手算第一天；[代码](../../examples/02_warehouse_eiq_abc.py)含拆行与每日核对。

策略先对应数据特征，再说明可验证方法。例如高IK与高EN提出不同作业假设；验证是否有收益需固定原策略、布局与评价口径。

## 继续、修复与停止条件

订单、商品、数量或日期缺失到无法恢复统计时，停止当前路线。EQ/IQ不一致先修口径；小样本没有ABC三类不必强行凑齐。

只有数据统计时可以完成描述与策略假设，但将实际提效标为待验证，不能随意填写节省百分比。

## 扩展与交付

有布局与作业数据时再比较储位、分区或批量拣选；模型与仿真应说明路线、设备、服务约束。模拟收益和实测分别报告。

交付包含每日EIQ、ABC结果、重点品项、差异化策略、阈值与适用条件、运行说明和报告。
